# Leapfrog interview field manual

A Next.js 16 app (static export) that turns one Markdown manual into an eight-stage, two-hour interview prep route, with cross-page ID previews, search, timers, saved progress and an interactive tech flow map.

## Quick start

```sh
npm install
npm run dev        # http://localhost:3000  (compiles content first)
npm run build      # production build -> ./out (static HTML)
npm start          # serve ./out at http://127.0.0.1:3000
```

Content compilation needs [`uv`](https://docs.astral.sh/uv/) (runs Python with `markdown` + `beautifulsoup4`, no global install).

## Editing content

Edit `content/manual.md` (or `content/stages.json`), then `npm run dev` or `npm run build`. Both recompile the content automatically.

## Features

- **IDs (R1, Q20, P1…)** link across pages; hover for a preview, click to jump with a highlight.
- **Search:** `/` or `Ctrl K`.
- **Timer** per stage that keeps running between pages; **route clock** shows each stage's planned window.
- **Progress, checklists and notes** (5.6 decide table, metric table) save in your browser's localStorage.
- **Tech flow map:** click any node for a numbered definition, how you used it, why it matters, and what comes next; ← → walks the chain.
