Writing code is one step of many. Between an idea and a happy user sit requirements, design, review, testing, release and operations, and most production problems are caused by a gap in one of those steps, not by a typo.

This part walks the lifecycle in order. Each lesson ends with what changes when the feature includes a model: evaluation joins testing, prompts join code review, and cost joins the release checklist. Part 10 goes deep on those AI-specific practices.
