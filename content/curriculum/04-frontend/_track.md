You don't have to be a frontend specialist to be a strong full-stack or applied AI engineer, but you must be able to build and reason about the interface. AI features live or die in the UI: a streaming answer that can be stopped, sources the user can check, and an "approve before send" button are product decisions as much as model ones.

This part uses React and Next.js (the App Router), the most common stack for AI product frontends.
